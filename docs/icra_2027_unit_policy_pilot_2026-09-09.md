**当前先做：用已有单 unit 模型训练一条 policy，验证挂接后的加载—保持—卸载**

2026-09-09。当前优先级高于[完整论文实验计划](icra_2027_unit_asset_plan_2026-09-09.md)中的 agent 辨识与正式多组 RL。状态：任务设计与代码接口核对完成，尚未实现新任务、启动训练或执行真机。这里的 policy 是 M0 的工程与迁移基线，不是完成接触模型验证的证据。

**首个 demo 的具体过程**

固定粗糙表面，机械臂末端使用一个 microspine unit，接触姿态与现有测量协议一致。通过既有流程建立挂接，再由 policy 在固定切向载荷目标下跟踪法向拉离载荷：低档 → 较高档 → 低档。各保持段以已有约 3 s 台阶协议为起点，改变载荷时平滑过渡。结束时降载到可复位状态，退出由已验证的固定操作或人工完成。首个 policy 的边界明确限定为挂接后的承载过程。

| 阶段 | 首版执行者 | 验证内容 |
| --- | --- | --- |
| 接近、预压、seating | 固定流程；必要时人工辅助 | 可重复获得符合旧建模协议的初态 |
| 拉离载荷逐渐增加 | Policy + 固定低层控制器 | 实际载荷跟踪、超调和意外脱落 |
| 保持与载荷切换 | 同一条 reference-conditioned policy | 多目标响应及短时保持 |
| 降载 | Policy | 载荷下降时是否仍能平稳控制 |
| 退出/复位 | 经台架确认的操作；未确认时人工 | 只记流程结果，不声称学会主动释放 |

接触点在墙面上保持近似不动是预期行为，不给焊接接触同时施加大幅贴墙画圆/移动目标。画面重点是接触特写、目标与实测载荷、位移和完整的成功/失败过程。末端拉载是真实负荷，不能靠持续压墙代替拉离承载。首版不增加动态负载物体、滑轨或整 pad，也不把固定底座机械臂演示称为攀爬。

**目标与模型范围**

选择已有数据覆盖的一个切向载荷档位，侧向载荷目标接近零；姿态固定，力矩维持在当前台架的已检查范围。两个法向目标取自已有多次稳定承载的区间，结合经验分布和初始接口检查确定，不能从单次最大值或全局均值直接指定。具体牛顿数、力误差容差、位移限值及执行器动作限幅仍待日志提取与接口标定，当前文件不是可直接上机的数值配置。

M0 冻结为当前单 unit 经验分布、现有接触响应及执行器设置的版本快照。保留挂接间随机性；每次挂接抽样后在该次挂接内保持随机分位数，载荷变化不重抽。经验表的支持域、删失标记与加载失败概率都保留。首次从较容易的域内目标训练，但不通过筛选强挂接 seed 来提高成功率。

现有曲线主要约束成熟接触的失效。位移—反力响应仍依赖软约束、安装与控制模型；这些假设应随 M0 保存。先做必要的坐标、力符号与控制响应检查，再训练；不把它扩展为一轮完整 agent 辨识。台阶升降与多段保持的真实效果仍待验证，不从静态分布直接声称动态正确。

**最小 policy 设计**

- 参考：固定切向目标与分段平滑的法向载荷时间表；训练随机化域内目标幅值和时序，测试预先留出的组合。不需要 AI 先生成参考。
- 初态：仿真通过固定建立流程获得成熟挂接状态，或由同流程产生并保留接触历史的初态库恢复。保留原始随机量，记录建立失败。真机用同一建立协议；加载阶段的条件成功率与包含建立失败的全过程成功率分开报告。
- 观测：真机可得的关节/TCP 状态、实际工具 wrench 及短历史、当前/短期参考和上一步动作。仿真真实挂接状态、抽样强度、精确失效裕量不进入 actor。
- 动作：在接口未确认前，按 rake—法向平面内的小幅 TCP 位姿/平衡点增量设计，姿态与侧向自由度由固定控制器维持。动作需要与真实接口一一对应；不能把遥操作的 CPU 力矩注入默认视作可部署接口。
- 奖励：实际法向/切向载荷跟踪、低超调、姿态/侧向保持和动作平滑；意外脱落结束该次尝试。只保持接触、没有达到规定拉离载荷不算成功。受力方向不同时追踪相互冲突的硬位置和硬力目标。
- 算法：小型 PPO，先一条 policy、一个 seed 跑通训练与回放；成功后才扩展种子和正式比较。保留参考条件化思路即可，不把该机械臂力跟踪任务写成已复现 BeyondMimic。

如果真机提供的是直接力目标接口，动作设计需随之调整。若现成力控器直接接收参考便能完成全部任务，则本任务仍可用于接口和迁移检查，但不能把目标转发包装成有意义的 RL 控制贡献；后续任务是否需要学习根据实测决定。

**怎样检验这个 pilot**

先完成三个仿真检查：unit 受力确实进入当前经验表；越过支持/失效条件会按模型结束；冻结 policy 在独立随机样本和留出参考上评估。观测中的力需对应实际 F/T 可测的工具净 wrench，不能只读普通几何接触压缩力而漏掉挂接约束反力。

真机首轮建议三种短协议：低档保持、较高档保持、低—高—低；每种 5 次独立挂接尝试，共 15 次 policy pilot。该数量仅用于发现接口与迁移问题，不是论文正式统计量或高可靠性证明。启动检查、中止、失败与重试全部保留。

用同一参考的合理反馈控制器作诊断对照；若也完成三种协议各 5 次，则首轮总计 30 次。这一对照用于判断 RL 接口是否退化、低层控制是否已解决任务，不另启动多种 agent、模型库或大规模训练矩阵。接口开发试验可以只先执行其中最简单的一种。

记录实际力跟踪误差、超调、保持时长、unit 相对滑移、意外脱落和各阶段结果。统计分母保留建立失败；条件加载指标可以另列。真实 pilot 反馈可用于随后开发和 agent 诊断，因此不混入后续模型修订后的独立终评。

视频连续展示固定流程建立、policy 接管、两档拉载和降载，并叠加同步的目标/实际力曲线及实际位移。成功录像配合全部尝试的计数；仿真预测不确定性与实测表现分别标注。可展示一次失败用于定位差异，不为拍视频故意抬高未检查的载荷。

实现顺序是：独立单 unit task/适配器 → 观测、参考、动作和奖励 → 单环境加载检查 → 一个 seed 训练 → 独立仿真回放 → 上机 pilot。环境缺口属于接入已有物理模型的工程工作，不要求先完成新的接触辨识。

这一步的输出是 M0 快照、训练配置、policy checkpoint、参考集合、仿真评估及真机 pilot 日志。若出现稳定的真仿偏差，它自然成为下一阶段 agent 辨识的目标；若简单任务已经迁移成功，再决定增加哪项有实际用途的接触动作。完整论文计划中的 E1–E4 和次数暂作为后续设计，不是当前 pilot 的启动门槛。
