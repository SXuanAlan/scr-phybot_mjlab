# Documentation

- `tasks/`: task guides. [climb_wall](tasks/climb_wall.md) and
  [brick](tasks/brick/README.md); the walk, squat and transition80 configs
  document themselves in their `config/phybot_c2/` module docstrings.
- `microspine/`: the pad model. [state_machine.md](microspine/state_machine.md)
  covers engage, hold and release; [phybot_c2_cad_asset.md](microspine/phybot_c2_cad_asset.md)
  covers how the pad CAD becomes the robot asset.
- `figures/`: paper figures (svg, pdf, png and a caption each). The scripts in
  `scripts/microspine/` and `scripts/reference/` regenerate them.
- `paper/`: method write-ups in LaTeX.
- `plans/`: current plans, including `icra2027/`.
- `reports/`: analysis reports with their figures; `empirical_climb/` holds the
  September design reviews and evaluations of the empirical climb.
- `reference/`: papers this work builds on.
- `archive/`: retired designs, notes and plans, kept for history.
  [RETIRED.md](archive/RETIRED.md) lists the retired code and how to get it back.
