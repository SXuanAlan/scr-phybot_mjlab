# 整 pad bench 验证协议草案

状态：实验材料准备完成，尚未执行真实机械臂实验。矩阵中没有实测结果。
候选载荷用于讨论覆盖范围；夹具、传感器、机械臂、限位的额定范围尚未提供，
因此它不是可直接运行的控制程序。实际执行上限必须取设备额定范围与试验目标的交集。

## 研究问题

1. 单 unit 分布、等刚度分配、unit 独立采样，能否预测整 pad 的保持和释放？
2. 首次 unit 释放后是否立即整 pad 脱落，还是仍能承载并重新分配？
3. 完整力矩模型相对只考虑力的模型，能否减少错误预测“可以保持”的事件？
4. CAD 的 B→C 偏置（约外偏 47.50 mm、纵向偏置 77.98 mm）以及球铰自由段/限位，是否与模型里的载荷路径一致？

## 夹具与测量量

使用与 asset 对应的 4×3 完整 pad、实际球铰与支撑件，记录打印方向、填充、
称重质量、unit 更换记录、间距、B→C 偏置、关节自由度、限位角度。
刚性锁死的夹具试验只能验证刚性安装下的 pad，不能直接替代被动球铰/限位验证。

定义 S 为腕部传感器参考点、C 为接触阵列中心。先完成传感器零偏和工具重力补偿，
再把 force、moment 和位置向量转到同一个世界或 pad 坐标系：

```text
F_C = R_CS * F_S
M_C = R_CS * M_S - (C-S)_C cross F_C
```

这里的 F/M 必须采用同一作用方向。若传感器输出环境作用在工具上的反力，
而模型输入是机器人施加给接触的载荷，两者要整体取反；力和力矩不能只反一个。
用已知方向的压墙、拉脱、剪切和已知力臂检查符号，再做对照。
标定后的 C 点数据与未经变换的原始传感器数据都应保存。

## 加载与事件定义

主实验沿用单 unit 数据的协议条件：先 seating，再达到剪切/侧向加载条件，
最后法向逐级卸压/拉脱，每级保持 3 s。120 N 整 pad seating 是 12×10 N
均匀分配的近似，需要检查实际接触，不能仅凭腕部总力认定所有 unit 都挂附。
另一预压的 5 次试验标为探索组，现有条件分布不直接对它声称定量精度。

法向扫描步长候选为整 pad 6 N；零力矩均匀分配时对应 unit 0.5 N。
力矩扫描建议 0.1 N·m/级，侧向扫描 6 N/级，同样每级 3 s。
矩阵中 1.2 N·m 的力矩是用于起步讨论的扫描终点，不是测得的 pad 或限位额定容量。
应保存完整加载路径；先后加载次序变化是独立因素，不能混入同一个极限面。

同一试验分别记录：首次可见部分释放、首次滑移、最终脱落、机构到限位、
表面剥落、机构卡滞和夹具异常。原 unit 的 0.3 mm 跳变与 3 mm 终止门槛
可作为初始候选，但整 pad 必须结合转角、视频与夹具柔顺性校核，不能未经验证照搬。
到达扫描上限仍保持的结果记为右删失，记录最后保持载荷，不能记成“失效于上限”。

每次记录最后稳定台阶、最后一级实测峰值、首次释放事件、最终事件时刻的
指令与实测值。最终事件读数可能已掉载；比较容量时不能仅用这一行。
原始 RT 记录、100 Hz 或更高频明细、视频都保存各自时间戳，统一同步基准。
不要把力控跟踪误差小当作接触模型准确的证据。

## 矩阵与数据划分

`pad_bench_matrix.csv` 含 60 次计划独立重新挂附：

- 3 个顺纹剪切条件下的法向扫描，各 5 次，共 15 次。
- 正/负侧向扫描、正/负 peel、正/负 roll、正/负 twist，各方向 5 次，共 40 次。
- 较低预压下的法向扫描 5 次，单列探索组。

主实验每个条件的 rep 1–2 为 calibration，rep 3–5 为 held-out validation。
实施前分配不同位置/独立试件并冻结清单，不复用同一挂附的前后段作两套数据。
随机化实际执行顺序，均匀穿插条件，记录表面位置与累计使用，避免磨损与条件混淆。
模型定型后在保留组上同时评价完整模型和 force-only 模型；所有结果都保留。
不同 substrate failure 单独标注并计入总体统计，再说明模型不覆盖的机制。

评价：终末/起始释放预测误差、各概率区间覆盖率、保持概率的 Brier 分数、
错误预测保持的次数/比例、各条件成功次数/试验次数、试验间离散程度。
小样本比例应给区间；这些重复次数是工作量安排，不是统计充分性的保证。

## 限位与后续策略载荷

当前静力 reference 需要手部限位约 6.65 N·m，抽查最大约 7.37 N·m。
应单独核对承载构件、限位接触位置及变形；仅有 PLA 材料密度和估算惯量
不能给出这一装配的承载能力。记录自由行程与触及限位前后的实际反力矩。
不能通过锁死球铰、增加额外压墙支撑来无记录地帮助回放通过。

当前 `reference_static_loads.csv` 仅包含稀疏静力解，不是动态回放轨迹。
第 5 步获准并完成后，从冻结 checkpoint 的评估 rollout 导出带坐标/参考点标记的
高频 C 点 wrench、挂附状态、球铰角度和相位，再预先固定代表/边界/peel 片段。
应比较保持、滑移/脱落时刻、转角和重新挂附，而非只比较指令与跟踪力。
若缩放载荷，保存缩放比例，并且仅声称验证缩放后的需求。
