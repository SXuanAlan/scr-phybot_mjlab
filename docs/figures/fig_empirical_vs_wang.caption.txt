Bench unit boundaries compared with the current repository Wang-inspired implementation. Blue solid/dashed curves use pad F0=400/650 N and unit F0=F0/12; the shaded span is a configuration range, not a confidence interval. Red points and error bars are conditional terminal-command medians and interquartile ranges; hollow diamonds identify n=1 cells. The hollow triangle is a right-censored hold. All 275 detached_normal trials are retained; 20 early failures and one censored hold are outside the conditional median statistic. Normal staircase protocol: 10 N unit preload, 0.5 N steps, 3 s dwell. (a) Zero lateral load. (b) Fixed 20 N unit rake shear. Positive normal force is tensile. The old model has no tensile solution when the in-plane load already exceeds capacity; such curves end rather than reporting a negative normal failure boundary. (c) Peeling with zero net normal/lateral force and no other moments, using the same 3x4 rigid equal-stiffness grid (74.6 x 96 mm) for both models. The red curve is inferred from unit data and is not a measured pad moment boundary or reliability quantile. The empirical 360 N shear edge is the end of the measured unit domain, not ultimate pad shear capacity. This descriptive comparison is not held-out validation. The local baseline approximates selected paper features and is not a faithful digitization of the original Fig. 8; see the audit for its lateral/reverse anchor discrepancy.
